With that said, let's to the point. Typst The link goes to the documentation of this amazing tool for creating beautiful PDFs. In the same way I never use Overleaf (ok, for search only) I like using typst locally.

If you came from LaTeX, you must be used to some old tools which sometimes looks like a computer virus. Here you may have some difficulties too, but I judge there are less frictions.

At first you need RUST. Yes, but you don't need to know how to program in this strange language. Just install it. I won't put any link here. You have Google!

After install Rust, you need the Typst codebase (yes, it's open source). The source is here. So, just a git clone https://github.com/typst/typst works fine.

Now, you build it! In the README.md has instructions. I suppose you know how to read! RTFM!

Congratulations! You have the executable file. Now you can add to your env vars or do whaterer you want. I'm here to present you the typst.

I personally call it "the LaTeX of 21 century" because it is! It makes write an academic essay like write a README.md file. You can add graphs, figures, and more, without import many and many libraries, because it's native. Also, it generates small pdfs.

Take a look at a code example! 

#text(font: "New Computer Modern")[
    = Background
    In the case of glaciers, fluid
    dynamics principles can be used
    to understand how the movement
    and behaviour of the ice is
    influenced by factors such as
    temperature, pressure, and the
    presence of other fluids (such as
    water).
]

Yes! Just these lines of code works!

You don't need a "Preamble" or anytyng like that. It's just there, for your use and joy!

The = sign indicates a new title. How many equals signs, lower the title will be.

I invite you to discover more. They also have an Overleaf like platform. Enter the documents and see if it interest you.
